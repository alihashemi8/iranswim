# سامانه جامع مدیریت آموزشگاه شنا (IranSwim)
## Swimming Academy Management Platform

سیستم یکپارچه، ماژولار و آماده تولید (Production-Ready) برای مدیریت کامل آموزشگاه شنا شامل:
- **پنل اختصاصی ناظر فنی سامانه (Supervisor & Bug Monitoring)** جهت رصد زنده سلامت سرور، لاگ خطاها و باگ‌ها، استک‌ترس و ردپای حسابرسی.
- **پنل مدیر آموزشگاه (Admin)** برای مدیریت دوره‌ها، ظرفیت کلاس‌ها، تأیید درخواست‌های ثبت‌نام، صدور فاکتور و امور مالی قسطی.
- **پنل مربی (Coach)** جهت ثبت حضور و غیاب کلاسی (با اثر سهمیه)، ارزیابی مهارت‌ها و ثبت رکوردهای زمانی.
- **پرتال شناگر (Swimmer)** جهت مشاهده برنامه کلاسی، سهمیه باقیمانده، وضعیت اقساط و نمودار پیشرفت.
- **پرتال عمومی** برای معرفی دوره‌ها و ثبت‌نام آنلاین متقاضیان.

---

## 🛠️ فناوری‌های استفاده‌شده

- **بک‌اند:** Python 3 + Django 6 + Django REST Framework + SimpleJWT + Psycopg 3
- **فرانت‌اند:** React 19 + Tailwind CSS + Lucide Icons + Vite
- **تایپوگرافی و ظاهر:** فونت فارسی وزیرمتن (Vazirmatn) میزبانی محلی، کاملاً راست‌چین (RTL)، فقط حالت روشن (Light Mode) الهام‌گرفته از تم آرام و روشن بخار.
- **پایگاه داده:** PostgreSQL با قیود یکپارچگی، تراکنش‌های اتمیک و Decimal دقیق برای محاسبات مالی.
- **تست خودکار:** Pytest + Pytest-Django

## 🚀 راهنمای اجرای محلی (Local Development)

### ۱. اجرای بک‌اند (Backend)
```bash
# ایجاد و فعال‌سازی محیط مجازی
py -m venv venv
.\venv\Scripts\activate

# نصب وابستگی‌ها
pip install -r backend/requirements.txt

# اعمال مایگریشن‌ها و ایجاد داده‌های اولیه
python backend/manage.py migrate
python backend/manage.py seed_data

# اجرای سرور جنگو
python backend/manage.py runserver 0.0.0.0:8000
```
آدرس‌های مهم:
- مستندات تعاملی Swagger API: `http://localhost:8000/api/docs/`
- فایل اسکیما OpenAPI: `http://localhost:8000/api/schema/`

### ۲. اجرای فرانت‌اند (Frontend)
```bash
cd frontend
npm install
npm run dev
```
آدرس فرانت‌اند: `http://localhost:5173/`

## 🧪 اجرای آزمون‌های خودکار (Automated Tests)

```bash
.\venv\Scripts\pytest.exe
```
تست‌های پیاده‌سازی‌شده شامل:
- احراز هویت و توکن‌های JWT بر اساس نقش‌ها
- سرویس پایش سلامت ناظر و تاخیر دیتابیس
- تست شبیه‌سازی باگ و ضبط خودکار استک‌ترس در Middleware
- تست حضور و غیاب و کسر هوشمند سهمیه جلسات
- تست دقت محاسبات مالی Decimal و تخصیص اقساط
